# JobScope-Canada-Analyst-Job-Market-Intelligence-Platform

VS Code → Build the scraper, automation, and Streamlit dashboard.
Jupyter Notebook → Perform analysis, create charts, and explain insights.
GitHub → Showcase the complete project.

Initially evaluated Scotiabank's careers website. Through HTTP inspection and browser network analysis, determined that job listings were dynamically loaded and therefore selected a more suitable public data source for the initial version of the pipeline.
